📌 가장 쉬운 방법 (추천!)
────────────────────────────────────────────────────────────────

  🖱️ "진단도구_실행.bat" 파일을 더블클릭하세요!

  → 자동으로 서버가 시작되고 브라우저가 열립니다.
  → 창을 닫으면 서버가 종료됩니다.

────────────────────────────────────────────────────────────────

📌 다른 방법들
────────────────────────────────────────────────────────────────

방법 1️⃣: START_SERVER.bat
  - 더 자세한 정보를 보여주는 서버 실행 스크립트
  - 모든 페이지 링크를 한번에 표시

방법 2️⃣: XAMPP로_복사.bat
  - XAMPP를 사용하는 경우
  - 프로젝트를 C:\xampp\htdocs로 자동 복사
  - XAMPP Control Panel 자동 실행

────────────────────────────────────────────────────────────────

⚠️ 주의사항
────────────────────────────────────────────────────────────────

1. 파일을 직접 더블클릭하지 마세요!
   ❌ diagnose_chinese.html을 직접 열면 CORS 에러 발생
   ✅ 반드시 .bat 파일을 통해 서버를 시작해야 함

2. PHP가 필요합니다
   - XAMPP, WAMP, 또는 Laragon 설치 필요
   - 스크립트가 자동으로 PHP를 찾습니다

3. 서버가 실행 중일 때
   - 검은색 CMD 창을 닫지 마세요
   - 창을 닫으면 서버가 종료됩니다

────────────────────────────────────────────────────────────────

📊 접속 주소
────────────────────────────────────────────────────────────────

서버가 시작되면 다음 주소로 접속하세요:

  🔍 진단 도구 (메인):
     http://localhost:8000/diagnose_chinese.html

  🌐 중국어 메인 페이지:
     http://localhost:8000/index_cn.html

  ⚙️ 관리자 페이지:
     http://localhost:8000/admin.html

  🗄️ 데이터베이스 테스트:
     http://localhost:8000/direct_db_test.php

────────────────────────────────────────────────────────────────

❓ 문제 해결
────────────────────────────────────────────────────────────────

Q: "PHP를 찾을 수 없습니다" 에러가 나요
A: XAMPP를 설치하세요 → https://www.apachefriends.org/

Q: "포트가 이미 사용 중입니다" 에러가 나요
A: 다른 프로그램이 8000번 포트를 사용 중입니다.
   실행 중인 서버를 종료하거나 다른 포트를 사용하세요.

Q: 브라우저가 자동으로 안 열려요
A: 수동으로 브라우저를 열고 주소를 입력하세요:
   http://localhost:8000/diagnose_chinese.html

────────────────────────────────────────────────────────────────

✅ 성공 확인
────────────────────────────────────────────────────────────────

진단 도구가 정상적으로 열리면:
  ✓ 주소창에 "http://localhost:8000"으로 시작
  ✓ "Test 1: API 응답 확인" 섹션에 데이터 표시
  ✓ 한국어(빨강), 영어(파랑), 중국어(노랑) 데이터 비교표
